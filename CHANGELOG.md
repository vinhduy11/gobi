# Changelog

All notable changes to this project are documented here. Format: [Keep a Changelog](https://keepachangelog.com/).

## [Unreleased]

### Changed
- Internals: the bottom panel keeps its tabs by id (`PanelTab`), so adding a tab no longer shifts saved sessions or call sites (old sessions migrate); the language client advertises hierarchical document symbols and reads symbols with ranges, detail and document version (`DocumentSymbolInfo`). References, Implementations and hover answers that were overtaken by a newer request or an edit are dropped (code lens counts and completion already were).
- Every menu item starts with an icon (SF Symbol): the menu bar, the right-click menus, the ⋮ menu and the lists of branches, recent files and projects, toolchains and environments. macOS 26 drew icons only on items with a system action (Cut, Copy, Paste, Hide, Quit, Minimize…), so the menus looked uneven; those items now carry an explicit icon like the rest. Names are in `GobiModel/MenuIcons.swift` (one entry per menu title, tested), and the self-test checks that no item is bare.

## [0.1.0-alpha.2] - 2026-11-06

### Added
- Run and Debug in the right-click menu of a Go file, in the Explorer and in the editor, named after the file (`Run ‘main.go’`, `Debug ‘main.go’`); a test file offers `Run Tests in ‘x_test.go’` instead of Debug, limited to its package; other rows get neither.
- Folders without a go.mod: Run passes the Go files of the folder (`go run main.go util.go`, the files that share the open file's package) instead of `.`, and Run Tests passes them with the `_test.go` files; the Output pill shows what ran. A go.mod in the folder or a parent inside the project, or a go.work, keeps the old behaviour. The core run channel accepts several `.go` files for run and test (no `..`, no absolute paths, not mixed with package patterns).
- A notice in the editor for a Go file in a project with no go.mod: "Create go.mod" and "Not Now" (remembered per project; Restricted Mode shows the text without the button). Create go.mod writes `module <folder name as a module path>` and `go <major.minor of the Go in use>` in the project root, refreshes the explorer, the inspector and the status bar and restarts gopls for the open Go files. Also in the Explorer menu (only while go.mod is missing and the project is trusted).
- Explorer > New > Go Package…: a folder and a file of the same name with `package <name>` (the name must be a Go identifier and not exist yet).

### Fixed
- Accepting a completion left the letters typed after the list opened: typing `pac` and choosing `package` gave `packageac`. gopls' replace range is worked out when the request is sent (after `p`), so the later `ac` was not replaced; the range is now stretched to the caret.
- The Source control block under the Explorer and the bottom panel (Problems, Tests, Terminal, Output…) had a fixed height; both now have a divider you can drag (minimum heights keep them usable, the position is remembered).
- A double click on a folder in the Explorer opens or closes it.
- Git status could show an older state: refreshes run side by side and a slow, older answer arriving last replaced the newer one (changed files missing from the Commit tab, a ticked file losing its tick). Only the newest refresh is applied now.

## [0.1.0-alpha.1] - 2026-11-06

### Added
- Terminal font: Settings > Terminal has a font family (SF Mono, Menlo, Monaco, Courier New and any installed Nerd Font), and installed Nerd Fonts are used automatically for the Powerline and file-type icons that prompts such as powerlevel10k and starship draw, which showed as boxes before. When no Nerd Font is installed the pane says how to get one.
- Explorer drag and drop: drag files and folders onto a folder to move them (open tabs follow; never into itself or outside the project).
- `docs/macos-security.md`: how to open an unsigned alpha on macOS (Open Anyway in Privacy & Security on macOS 15 and later, right click > Open before), the checksum check, the permission prompts, what Gobi does on your machine, and how to remove it. Linked from the README and the release notes.
- Typing help in the editor: a bracket or quote types its partner (`{` gives `{}`, with the caret between), a closing bracket typed before the same one moves over it, Backspace between a pair removes both, an opener typed over a selection wraps it, and a quote after a word (an apostrophe) is left alone. Return keeps the indentation of the line, one level deeper after `{`, `(` or `[`, and between `{` and `}` it opens a block. Two switches in Settings > Editor ("Close brackets and quotes", "Keep indentation on a new line"), on by default; nothing happens while an input method is composing text.
- Explorer > New > File…, Folder…, Go File… and Go Test File… make the entry in the clicked folder (or next to the clicked file), refresh the explorer and open a new file. A Go file takes the package of the Go files already in the folder, else the folder's name; a test file gets the `_test.go` suffix and a `testing` import; a name that exists, is empty or contains `/` is refused with a note in the status bar.
- Versioning for releases: the `VERSION` file (Semantic Versioning, now `0.1.0-alpha.1`) is the one source. `make-app.sh` writes it, the build number (the number of commits) and the commit into Gobi.app and into `gobid` (`gobid version`); About Gobi shows them; the DMG is named `Gobi-<version>.dmg` with a `.sha256`. `scripts/release.sh VERSION` cuts a release on `main` (VERSION, CHANGELOG section with compare links, commit, annotated tag `vVERSION`), `scripts/release-notes.sh` writes GitHub release notes (summary, Download table with checksums, What's new, All changes, Full Changelog) and `scripts/publish-release.sh` creates the GitHub release (pre-release for alpha, beta and rc) with the GitHub CLI. See `docs/release.md`.
- Git: Amend (the git channel's commit request has a flag that amends the last commit; ticking Amend with an empty message fills in the last message) and a Stash segment listing the stashes with Apply, Pop and Drop (git channel kinds 36 to 39, a number field holds the stash index). Commit and Push commits, then pushes.
- Explorer > Cut, Copy, Paste, Delete…, Refactor > Rename… (⇧F6) and Move… (F6) work (also ⌘X ⌘C ⌘V ⌫ in the explorer). Cut and Copy put the file URLs on the pasteboard, so Finder can paste them and Gobi can paste files copied in Finder; a name already there gets `name copy.ext`, `name copy 2.ext`; a folder cannot go into itself. Delete asks first (naming the items and any unsaved edits) and uses the Trash. Rename and Move keep open tabs (text, caret, unsaved edits), breakpoints and the language server in step, also for files below a renamed folder. Only items inside the project folder are touched. The explorer keeps its expanded folders and no longer opens files by accident after a refresh.
- Explorer > New > File…, Folder…, Go File… and Go Test File… make the entry in the clicked folder (or next to the clicked file), refresh the explorer and open a new file. A Go file takes the package of the Go files already in the folder, else the folder's name; a test file gets the `_test.go` suffix and a `testing` import; a name that exists, is empty or contains `/` is refused with a note in the status bar.
- Logs: `gobid` writes its JSON log to `~/Library/Logs/Gobi/gobid.log` (`-log FILE`, `-` for stderr; `GOBI_LOG_DIR` moves the folder) and the app writes `gobi.log` there (start with version and system, clean quit, gobid connection problems, missing go/gopls/dlv, run/debug/terminal start errors, uncaught Objective-C exceptions, fatal signals). Private files, rotated at 2 MB with four old copies; paths are reduced to their last element. A panic while serving one client is logged with its stack and no longer takes gobid down. `gobid version` prints version, commit and platform. A `running` marker tells the next start that the last run ended abnormally (a notice with Reveal Logs). Help > Open Logs Folder and Copy Diagnostics; Settings > Advanced has Open Logs Folder.
- `ui/macos/scripts/make-dmg.sh` packs `dist/Gobi.app` into `dist/Gobi-<version>.dmg` with an Applications shortcut.
- Run on Multiple Go Versions keeps the last result per project (vet and test per Go version: pass or fail, time, a short output excerpt shown as a tooltip) in preferences under `gobi.multiversion.<project>`, shows it again when the window reopens with a "last run: 5 min ago" line, and has a Clear button. The Install Version sheet now has Cancel next to Done and is covered by the toolchain self-test as a sheet on the Toolchains window. Mock updated.
- Settings > Advanced: the Large files limit now applies to files that are already open (read-only past the new limit, editable again under it), and a new gopls path restarts the language server of open Go files at once; the captions no longer say "applies to files opened after the change". `--selftest-settings` covers both.
- Unsaved-edit recovery is also written every 20 s while a project window is open (only buffers whose text changed since the last write), so a crash no longer loses the edits; buffers are still deleted on save, discard and close of the tab.
- Profiler Source view shows just the selected function (its declaration line to its closing brace, found by a brace scanner that skips strings, runes, raw strings and comments) with a "Show whole file" checkbox. `profile/lines` also returns the function's declaration line (field 3).
- Code lens: a grey "N references · M implementations" after each top-level func, method, type and interface method of a Go file, and "run test" after test functions; a click runs Find References, Go to Implementation or the test. Counts come from gopls for the declarations near the screen, after typing or scrolling pauses, cached per declaration and document version, at most 200 a file. Settings > Editor > Show code lens (default on). Drawn at the end of the declaration line, not in a line above it (mock updated). `--selftest-codehelp` covers counts, the implementation lens, the click flow, caching and the switch.

Build menu: Build Project (`go build ./...`), Build Module (the open file's package), Rebuild Project (`go build -a ./...`), output in the Output tab. Run menu: Stop (debug session or run), Resume/Step actions, Evaluate Expression…, View Breakpoints…. Edit: Copy Path, Sort Lines, Reverse Lines (one undo step), Paste as Plain Text, Start Dictation…, Emoji & Symbols. View: Recent Files (kept per project), Reset Font Size in All Editors. Window: New Window, Next/Previous Project Window (⌘`, ⇧⌘`). Shortcut conflicts with existing Gobi keys are listed in `docs/implement/menu-shortcuts.md`.
- gobi daemon: git channel kinds 15–35 (tag, reset, stash, unstash, abort merge, rebase with abort/continue/skip, patch, apply patch, continue/abort revert and cherry-pick, remotes, worktrees), a list reply (kind 8), a second text argument (field 9) and an `operation` field in the status reply; the run channel's `build` accepts `-a`. git never opens an editor (`GIT_EDITOR=true`).
- Tests panel: a "Filter tests" box narrows the tree by a case-insensitive substring of test or package names (Esc clears).
- Find in Files: Replace on a single match, a per-file checkbox that leaves a file out of Replace All, and a dropdown with the last 10 searches. Mocks updated.
- Signature help: typing `(` or `,` inside a call shows gopls' signature in a small popup above the caret with the active parameter in bold; Esc or `)` closes it; Edit > Parameter Info (⇧⌘Space) asks on demand. Snippets in completion: gopls' snippet items insert their text, select the first placeholder, Tab moves to the next one and ends after the last (`--selftest-codehelp` covers both).
- Profiler: a filter box narrows the Top table and the flame graph by function name; a Source view shows the selected function's file with flat and cumulative cost per line (double click opens the file at that line); Compare… diffs the open profile with another file (Top sorted by absolute change); the Capture menu gains Allocations, Goroutines, Mutex contention and Blocking presets. New control methods profile/lines and profile/diff.
- Git: Merge into Current Branch… in the branch menu (pick a branch, confirm; a merge commit is made without an editor, and a conflict aborts the merge, leaves the tree as it was and names the files). gobid: git channel kinds 13 (merge) and 14 (fetch).
- Settings that were drawn disabled and are now live: Terminal start folder (project or home), scrollback lines and Copy on select; Confirm before quitting with unsaved changes or running work; Git program path and Fetch interval (the app fetches on a timer while a project window is open); gopls path; Large files (the line length over which a file opens read-only). The handshake has a `tool` field (git path on the `git` channel, gopls path on the `lsp` channel). "Check for updates automatically" stays disabled: there is no update server.
- A green Run button in the gutter on each test function of a `_test.go` file runs just that test.
- Go to Implementation (⌘F12, editor menu): gopls' implementations of the interface or method at the caret; one result opens at once, several are offered in a menu.
- Git: Pull (fast-forward only), Push (a branch with no upstream is published to the first remote; the button shows the count ahead) and Discard Changes… in the Changes list menu (asks first; a tracked file goes back to the last commit, an untracked one is deleted). gobid: git channel kinds 10–12; git never prompts for a password on a terminal.
- Output links and failing lines: a `file.go:12:5` mention in the Output panel (compiler errors, test failures, stack traces) is a link that opens the file at that line; picking a failed test, or a message under it, in the Tests tab does the same. - Release plumbing: `make-app.sh` signs with `SIGN_IDENTITY` (Developer ID, hardened runtime) and `notarize.sh` notarizes and staples with a keychain profile; `scripts/ci.sh` and `.gitlab-ci.yml` run the Go checks and, on a macOS runner, the Swift tests, layer check and build. ### Fixed
- After an update the new app kept using the old gobid, because the daemon outlives the app that started it, so fixes in gobid (such as the PATH fix) did not take effect until the old daemon was killed by hand. The first time the app connects it now compares the daemon's start time with the time the bundled `gobid` file was written, and when the daemon is older it asks it to stop and starts the new one. A daemon that is newer is never touched.
- Setup said `go` was missing although it is installed: an app opened from Finder or the Dock gets only the system `PATH`, so `/usr/local/go/bin` (the Go installer) and `/opt/homebrew/bin` (Homebrew) were not searched. gobid now adds those, the directories listed in `/etc/paths` and `/etc/paths.d`, `/usr/local/bin` and `~/go/bin` to its `PATH` at start, after the entries already there, so go, gopls, dlv and git are found the same way as in a terminal.
- Right-clicking in the Explorer did nothing in a project with no files yet (and below the last row of any project): the menu was only offered for a row. A click on empty space now gives the menu of the project folder.
- The first character of every line (`p` of package, `i` of import, `f` of func) was cut off after jumping to a line: revealing a caret near the left edge scrolled the editor sideways by about 14 pt. A small sideways offset is now taken back to the left edge.
- Find in Files no longer follows symbolic links, so a link inside the project cannot expose a file outside it.
- The git program from the handshake is now per session; a later connection no longer changes the program used by other sessions.
- Remote addresses and git error messages hide the password of `https://user:password@host` URLs.
- Profile capture no longer overwrites an existing `.pprof` file; it fails with an "already exists" error.
- Wire protocol doc: the `dap` channel is framed DAP JSON, not a translated binary channel.
- Auto save (after a delay, and on focus loss) no longer overwrites a file that changed on disk: it compares the disk with what was read, leaves the file alone and lets the Reload from Disk / Keep Mine notice ask (also while a restored-buffer notice is open). Git operations that rewrite files (discard, reset, stash, merge, pull, checkout, rebase and the like) cancel pending auto saves and afterwards check open buffers. An explicit save (⌘S, Save All) still overwrites after Keep Mine.
- Closing a project window with several edited tabs is all-or-nothing: every question is asked first, Cancel on any leaves the window, tabs, kept buffers and disk watchers as they were, and only then are the saves and discards applied.
- Changes on disk are also recognised by file identity (inode) and, after a file-system event or when a kept buffer is restored, by a content digest (FNV-1a 64) when time and size are equal. The 10 s poll does not read files. Kept buffers written before this change still load.
- Kept (recovery) buffers are private: folders 0700, files 0600 written through a temporary file and rename; a failed write shows in the status bar; at app start records of files that are gone, older than 30 days or unreadable are removed; text of files that look like secrets (`.env*`, `*.pem`, `*.key`, `id_rsa*`, `credentials*`, `*.p12`) is never kept or restored.
- Passwords in remote addresses (`https://user:token@host/…`) are removed from the Manage Remotes list and from git error text shown in the UI (defence in depth next to the core's own redaction).
- Shortcuts customised under the menu item names of the previous menu bar (Debug menu items, Edit > Find > Find in Files…, Window > Show Next/Previous Tab) are moved to the current names once at launch.
- Feature self-tests (`--selftest-NAME`) no longer open the folder argument as a real project as well (which restored a session, asked about trust and started the file watcher).
- Typing in a large file took about 110 ms per key because completion copied the whole text on every keystroke; it now reads only the identifier before the caret (about 3 ms on a 100k-line file).
- The built-in self-tests no longer leave their changes behind in the app's preferences (editor settings, terminal shell, toolchain and breakpoint choices): `exit` skipped their clean-up, so they now run it before leaving.
- A branch that is not the current one lost its first letter in the branch list.
- Run no longer stops with "Go X is not installed" in Auto mode while the installed Go versions are still loading, or when go.mod asks for a Go that is not installed; only a pinned version that is gone stops a run.
- `ui/macos/`: the bottom panel tabs and the terminal strip are easier to tell apart: tabs have room around their names, the current one has an accent underline and bolder text, the new-terminal and menu buttons are separate square buttons with a hover highlight and a divider before them. The self-test checks the spacing and that exactly one tab is current.
- `ui/macos/`: a menu item built with a method named `perform` crashed when chosen, because the name collides with `NSObject.perform(_:)`.
- `ui/macos/`: the project window no longer shrinks itself to the layout's fitting size (a holding priority above Auto Layout's window priority did it), and a saved window frame that is too small is ignored.
- `ui/macos/`: the tabs were never visible. The tab strip was a stack used as a scroll view's document view without constraints, so every tab had size 0 by 0. It is pinned now, has a background of its own with a hairline, and the project self-test checks that each tab is drawn with a real size (and writes a window snapshot with `--snapshot`).
- `ui-macos/` and `core/`: a lone `\r` is a line break in `LineIndex`, `lsp` text sync and `langsvc` positions, as the protocol defines.
- `ui-macos/`: `GobiApp --selftest` and `gobi-check` run quietly (no window, focus change or Dock icon); `--visible` shows the window.
- `ui-macos/`: syntax colours no longer go stale or sit at the wrong offset after an edit (closing `/* */`, typing in
  front of a keyword, replacing the text). TextKit ran the colouring validator while it was still synchronising the edit
  and then shifted the colours just written by the edit's length; the editor now recolours the changed lines in the
  viewport once the edit is fully processed (`EditorContentStorage`, `SyntaxHighlighter.recolourAfterEdit`).
- `ui-macos/`: `gobi-check highlight` read a neighbouring run's colour for uncoloured text; it now checks the run that
  contains the offset, checks that token colours line up with the tokens, and writes PNGs of the editor with `--png-dir`.
- `ui-macos/`: a diagnostic underline no longer removes the syntax colour of the text under it (underlines now add and
  remove only their own rendering attributes through the shared `DiagnosticUnderlines`).
- `ui-macos/`: paint measurements (self-test, `gobi-bench`, `gobi-check`) use `flushPendingPaint()` (`CATransaction.flush`)
  instead of `displayIfNeeded()`, which paints nothing here; the self-test checks the gutter is painted per keystroke.
- `ui-macos/`: an LSP request that times out no longer leaves its pending entry behind; a late response is dropped.
- `ui-macos/`: VoiceOver line queries (insertion-point line, line for index, range for line) are answered from `LineIndex`
  by `EditorTextView`; the 100k-line file went from 7.9 s to under 0.01 ms for the caret line, and keystrokes after the
  queries from 220 ms to 3.8 ms.
- `ui-macos/`: lines over 20,000 characters are not syntax coloured (their keystroke cost drops from about 13 s to about 150 ms
  on a 1 MB line), and the status line says so.
- `ui-macos/`: dragging the scroller thumb no longer lays out every place the drag passes. Big jumps are deferred until the
  drag ends and applied once (trade-off: the text does not follow the thumb while dragging). Keystrokes after a full drag of
  a 100k-line file go from 10.4 ms to 2.1 ms, and memory growth from +139 MB to +26 MB.
- `ui-macos/`: `GobiApp FILE --selftest` exits with code 1 at once when FILE cannot be read, instead of waiting forever.

### Changed
- The window toolbar is redrawn in the IntelliJ style (mock updated): flat icon buttons without capsules, project and branch on the left, the run configuration with a green Run, Debug and Profile in the middle, then environment and Go version, and search and the inspector toggle on the right. The gopls status moved out of the toolbar (the status bar shows it).
- Layers made explicit. The Swift package is split into `GobiModel` (pure logic, no imports), `GobiClient` (gobid connection), `GobiEditor` (AppKit editor) and `GobiApp`; `scripts/check-layers.sh` enforces the imports. The Go core is ordered as foundation, services, transport, composition and entry point; `internal/layers` enforces the imports. See `docs/architect/layers.md` and the diagram `docs/diagram/gobi-layers.html`.
- The macOS UI moved from `ui-macos/` to `ui/macos/`, so `ui/windows/` and `ui/linux/` can sit beside it. Older entries below keep the old name.
- The handshake and the control channel are binary now (protobuf wire format, hand-coded in `internal/wire` and `GobiClient/Wire.swift`, no dependency). A JSON handshake is refused with a reply that says so. The LSP channel still carries JSON-RPC because gopls speaks it and the broker passes the bytes through. Both sides test the same golden bytes; the wire parser has a fuzz test. Field layout in `docs/architect/wire-protocol.md`.
- `gobid` with no arguments now serves instead of printing usage.
