Editor tabs and saving

Specs

The project window showed one file at a time and could not save. Add tabs, an unsaved mark, Save, and prompts that stop edits from being lost.

Actions

  • GobiClient/TabStrip.swift (open, select, close with right-then-left neighbour, wrap-around next/previous, dirty marks) with 8 tests written first.
  • TabBarView; ProjectWindowController keeps one pane per tab, asks to save on closing a dirty tab or the window.
  • EditorDocument.isEdited, EditorPane.save(), File menu: Save, Close Tab, Close Window (⇧⌘W), next/previous tab.
  • Project self-test covers tabs, dirty state and, with --allow-writes, saving.

Tradeoffs

  • The unsaved mark stays after undoing back to the saved text; comparing against the disk text would cost a full compare per edit.
  • Closing a tab drops its pane (undo history and scroll position go with it); the cost of keeping closed panes alive is not worth it.
  • Files changed on disk by another program are not noticed yet.
