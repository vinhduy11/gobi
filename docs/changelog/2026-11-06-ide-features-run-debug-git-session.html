Gobi IDE features: run, debug, git, settings, session

Implementation report, 2026-11-06

Specs

Turn the editor spike into a usable Go IDE on macOS, with every screen built to a mockup on the canvas.

  • Run and test with a chosen Go version, environment profiles and a .env file; install missing tools and Go versions.
  • Debugging with dlv, profiling with pprof, Git, terminal, Find and Replace in Files, JSON and Markdown.
  • Editor and app settings; session restore; detection of files changed by other programs.

Tradeoffs

DecisionWhy
Polling for file changes (1 s)Simple and enough for a few open files; a file-system event stream can replace it without changing the decision model.
Unsaved edits are not restoredAvoids stale buffers surviving a crash over a changed file; revisit with a recovery file.
Secrets in the Keychain, never in profile filesProfile files can be committed.
Debuggee built outside the projectdlv would otherwise leave binaries in the user's folder.
Auto toolchain never blocks a runOnly a pinned, missing version stops a run.
Known gapEditor keystroke time is above the 16 ms budget in the benchmark; not changed here.
