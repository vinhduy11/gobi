New Project, Clone and Import dialogs

Specs

Offer the core's project requests in the app: create from a template, clone a repository, turn a folder into a module.

Actions

  • GobiClient/ProjectForm.swift (name, module path, clone URL checks; repository name from a URL) with tests written first.
  • GobiClient/ControlClient.swift: project/new|open|clone|import over the control channel.
  • GobiApp/ProjectDialogs.swift, File menu items, Welcome buttons, progress panel while gobid works.
  • gobi-check project DIR: real gobid, five templates, import, refusals.

Tradeoffs

  • Forms are alert-style dialogs with a grid: little code and native look, but no live "Will create" file preview from the mockup yet.
  • A project created in the app is trusted at once (the user wrote it); clones and imports ask.
  • The dialogs themselves are not driven by automated tests (they are modal); the logic under them is.
