Menu bar to the Menus mock

Specs

Make the real menu bar match Menus.dc.html: Gobi, File, Edit, View, Go, Build, Run, Git, Window, Help; Debug merged into Run; Git submenus (Patch, Uncommitted Changes, Current File). Items with a feature are live, the rest stay disabled. New git operations need core support: tag, reset, stash, unstash, abort merge, rebase (abort, continue, skip), patch and apply patch, revert and cherry-pick control, remotes, worktrees, and the operation in progress in the status reply.

Actions

  • Core: core/internal/gitsvc/ops.go (with ops_test.go, real temp repositories), git channel kinds 15-35, list reply, field 9, status field 7 (core/internal/daemon/git.go, git_ops_test.go); GIT_EDITOR=true for every git call; run channel build accepts -a.
  • GobiModel: MenuSpec rewritten from the mock, MenuAvailability (which item is enabled for a context), LineOrder and RecentFiles, git request/reply cases, GitOperation, GitRemote, GitWorktree; tests for each.
  • GobiApp: ProjectMenuActions.swift (git, build, run and edit actions with plain entry points), MenuActions.swift (app delegate actions, Recent Files menu, project window cycling), MainMenuBuilder selector map and item identifiers, validateMenuItem consults MenuAvailability.
  • Self-tests: menu bar titles and wiring (--selftest), the git operations (--selftest-git), Build and Stop (--selftest-run), Stop and View Breakpoints while paused (--selftest-debug), Sort/Reverse/Paste as Plain Text with undo.
  • Docs: wire protocol, CHANGELOG, mock-gap row, docs/implement/menu-shortcuts.md.

Tradeoffs

  • Where the mock's shortcut collides with a key Gobi already uses, the existing feature keeps it and the new item shows none (listed in menu-shortcuts.md). Debug keeps F5 over the mock's ⌘D.
  • The Debug menu is gone, so keymap overrides stored under the old item names no longer apply.
  • Dialogs for tag, reset, stash, rebase, remotes and worktrees are plain alert sheets; the mock has none for them yet.
  • Patch contains tracked changes only (git diff HEAD); new untracked files are not in it.
  • Rebase conflicts are left in progress and reported; Resolve Conflicts only lists the files and opens the first.
  • Not built, left disabled: Column Selection Mode (the text view has none), Quick Definition, Notifications, Show History and Annotate (no feature), and every other item the mock shows that has no feature behind it.
