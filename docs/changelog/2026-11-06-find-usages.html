Find Usages (2026-11-06)

Specs

A usage list for the symbol at the caret in a bottom-panel tab: header with counts, tree of file, enclosing function and line, a Tests checkbox, Rerun, Previous, Next. Find Usages is Option+F7. Find References and the code-lens click open the tab for more than one hit. Results must be right for unsaved buffers, must not be overtaken by newer requests or edits, and no file is read on the main thread. See docs/implement/find-usages.md.

Actions

  • GobiModel: UsageGroups (grouping, order, tests filter, 5000 cap, names, excerpt, line validation), UsageContext (stale check), SymbolFetchQueue (four at a time, generations, failures), UsageLineCache; PanelTab.usages; menu entries, icon.
  • GobiApp: UsagesPanelView, UsagesFeed; Find References and Find Usages go through the feed; --selftest-usages.
  • Tests: UsageGroupsTests, UsageEnrichmentTests (500 files, failure, cancellation, rerun generation, double answer), PanelTabTests, MenuSpecTests; the self-test covers the unsaved buffer, closed files read once, no main-thread reads, no cache misses while drawing, the Tests filter, Next, staleness, Rerun and a deleted file.

Tradeoffs

  • A reply is dropped when the origin file changed during the query (same gate as the other requests); a change after the result shows marks it out of date instead.
  • The symbols of closed files are asked again on each Rerun; a modification-time cache was left out until it is measured to matter.
  • A file changed on disk by another program does not mark a result out of date; the line check before opening still catches a moved or deleted line.
  • The Go to Implementation pop-up still reads files on the main thread; moving it to the panel is a separate change.
