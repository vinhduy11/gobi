IDE shell: welcome, project window, trust

Specs

Turn the single-file editor window into the start of the full app: open a project, browse its files, edit them, and respect workspace trust (roadmap slice 4, first part).

Actions

  • GobiClient/ProjectModel.swift: ProjectKind, FileTree, RecentProjects, TrustList with 8 new tests.
  • EditorPane extracted from the old window controller; EditorWindowController now only hosts one pane.
  • ProjectWindowController (explorer outline + editor area + status), WelcomeWindowController, ProjectStore (UserDefaults), trust dialog and ⌘O routing in AppDelegate.
  • GobiApp FOLDER --selftest project check.

Tradeoffs

  • One editor shown at a time, with panes kept per file; a real tab bar comes next.
  • Trust only changes how gopls runs (restricted when untrusted); Run, Debug, Test and terminals do not exist yet, so nothing else to gate.
  • New Project, Clone and Import need core support (project/* calls) and are not built yet.
