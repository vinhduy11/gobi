Terminal: recompute columns after layout

Specs

In the Terminal tab, pwd output wrapped after "servi" and the last character repeated to the right edge before "ce". Expected: the line shows as printed.

Actions

  • GobiTerminalView.layout() (TerminalPane.swift) re-assigns frame when the laid-out size changed, so SwiftTerm recomputes columns and the pty is resized.
  • Project and global branching rule now accept main as the base branch (docs/claude/git.md).
  • Checked by running the rebuilt app; the fault is gone. No automated test: GobiApp has no test target, and a headless SwiftTerm reproduction did not show the fault.

Tradeoffs

  • Chose a layout hook over finding which layout path skipped SwiftTerm's resize: the root path was not pinned down, the hook covers all of them, and costs one comparison per layout.
  • No unit test, because the fault could not be reproduced outside the app; a regression is caught only by hand.
