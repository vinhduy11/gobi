Generate: 22 design patterns (core)

Specs

Add the 22 classic patterns as Generate items, in idiomatic Go, with dialog parameters, insert into the current file or a new <pattern>.go, and the wire fields to carry parameters, the module Go version and the target. Core only, no UI.

Actions

  • patterns.go: pattern definitions, parameter parsing and validation (names, signatures, fields, type expressions), collision check against the package, placement.
  • creational.go, structural.go, behavioral.go: one template per pattern.
  • Wire: request fields 17, 18, 19; list item fields 6, 7 (additive). Docs and CHANGELOG updated.
  • Tests: 25 pattern goldens, real-toolchain build (gofmt, vet, test) with a generated example test per pattern, list, validation, collision, import, file target, version echo, wire bytes, daemon round trip.

Tradeoffs

  • Patterns are offered only outside declarations: keeps the popup short; struct-level offers can come later.
  • Collision detection parses the rendered snippet and compares declared names, so every template is covered without per-pattern code; names in other files of the package are not known to the core.
  • Stubs use named results and a bare return so the code compiles before the user fills it in.
  • Prototype copies maps with maps.Clone (Go 1.21+), not gated by the module version.
