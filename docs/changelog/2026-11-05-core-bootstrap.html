Gobi core bootstrap

Slice 1 implementation report, 2026-11-05

Specs

Build the foundation of a Go IDE (macOS first) as a cross-platform Go daemon, gobid, that supervises the official Go toolchain and serves native UI clients over a local socket. Slice 1 scope:

  • LSP framing shared by UI-to-core and core-to-gopls, defensive against malformed input.
  • Toolchain discovery and a doctor command (report only, never installs).
  • Private unix-socket transport: single instance, stale-socket recovery, peer-UID check, versioned handshake.
  • A gopls broker: shared server per workspace, id translation, cancellation, server-request routing, restart with document replay.
  • Workspace trust: untrusted workspaces cannot make go download or switch toolchains.
  • TDD throughout; tests against a scriptable fake LSP server, plus an opt-in test against the real gopls.

Measured on Apple silicon, Go 1.26.5 (core-side micro-benchmarks only): rewrite request id in an 868 KB completion list 8.3 ms to 0.7 ms; read id and method 4.7 ms to 0.58 ms; 4 KB frame write plus read about 1.4 µs.

Tradeoffs

DecisionChosen overWhy, and the cost
Broker owns the gopls sessionTransparent byte pipeNeeded for id translation, restart with replay and sharing one gopls between windows. Cost: the broker must track open documents and implement incremental edits.
Separate connection per channelOne multiplexed streamNo id or method collisions between LSP, DAP and control traffic. Cost: more sockets and handshakes.
JSON everywhere for nowBinary framing (msgpack, protobuf)gopls and Delve speak JSON; a binary UI leg would add a conversion on every message. Measured core cost is small. Revisit for Gobi-owned channels if the Swift spike shows decode cost.
Byte-scan id rewrite, duplicates refusedDecode and re-encode12x faster on large messages. Cost: a hand-written scanner, covered by tests and fuzzing; messages with duplicate id or method are rejected.
Trust flag set by the client, default untrustedCore-side persistent trust storeSmallest thing that lets the UI drive the restriction. The client is the same user, so this is a usability gate, not a security boundary. Only GOTOOLCHAIN=local is enforced so far.
Fallback socket directory under /tmp for long pathsFail when the path is too longmacOS limits unix socket paths to about 104 bytes. The fallback directory is still created 0700 and owner-checked.
Linear restart backoff, no crash-loop memoryExponential backoff with a circuit breakerSimple and testable. A gopls that crashes right after every start keeps retrying five times per crash cycle.
Unix onlyNamed-pipe transport nowmacOS first. Windows needs a pipe transport and a different lock and peer check.
Dynamic capability registration answered with nullForwarding registrations to the UIKeeps the broker simple; clients will not receive file-watch registrations from gopls yet.

Known gaps

  • No test yet for go.work changes, vendor mode, cgo-disabled files, per-file build constraints or an offline missing toolchain.
  • No CI configuration and no written dependency and licence review.
  • Swift-side decoding cost and end-to-end latency are unmeasured.
