Git as a Commit tab in the sidebar

Specs

Remove the bottom panel's Git tab and move Git to the left sidebar, laid out like IntelliJ's Commit tool window: Commit, Stash and Log segments, a toolbar, a changes tree with a checkbox per file, Amend, a commit message, Commit and Commit and Push, and a gear for Settings > Git. The bottom tab at index 5 stays and becomes Diff. Amend needs core support, and so does listing, applying, popping and dropping stashes.

Actions

  • Core: gitsvc.CommitAmend, StashList, StashApply, StashPop, StashDrop; git channel kinds 36 to 39 and the amend flag on kind 7, documented in wire-protocol.md; temp-repo tests and a daemon wire test written first.
  • GobiModel (no Foundation): CommitButtonState, ChangesTree (groups, check state, group toggle, collapse), StashEntry, CommitPanelMode; GitRequest.commit(_, amend:), .stashList, .stashApply/Pop/Drop with wire tests.
  • GobiApp: CommitPanelView (sidebar tab 4), DiffPanelView (bottom tab 5, titled Diff); the old GitPanelView and the commit sheet were removed. Controller: applyToggle, commit(message:stageAll:amend:push:), Amend prefill, stash operations, Show Git Log and Commit… select the tab.
  • Mocks: GitPanel and Main updated first. Self-tests: --selftest-git covers the tree, ticking, commit, Amend, Commit and Push to a bare remote, stash apply and pop, the Diff tab.

Tradeoffs

  • The diff opens in the bottom Diff tab, not in the editor area: editor tabs are tied to file buffers, so a read-only diff tab would touch the tab strip, session restore and saving.
  • A tick means staged, so the existing stage model is kept; Commit commits the staged files, or all changes when none is ticked.
  • The fifth segment is an icon with a tooltip, because five text labels are wider than the 260 pt sidebar.
  • Amend prefills the last commit's subject only (the log carries subjects, not bodies).
