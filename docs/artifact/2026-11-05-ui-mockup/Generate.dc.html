Items depend on where the caret is: a struct offers constructor, getters and setters, String(); a function offers a table-driven test; an empty file offers main(), handler and the rest. Where gopls has its own action (implement interface, generate test, fill struct) the item runs that action. Everything inserts as one undoable edit, then the file is formatted. The code follows Effective Go: getter Addr() not GetAddr(), doc comments start with the name, errors lower-case and wrapped with %w.
